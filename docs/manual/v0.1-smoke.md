# v0.1 local smoke

Copy-paste checks that the AgentGavel CLI, FakeAdapter, and the two unofficial
sidecars (Sire, LangGraph) produce a fingerprint + scorecard with the expected
provenance labels. Run from the repository root unless noted.

## Prerequisites

- Go toolchain (module `github.com/agentgavel/agentgavel`)
- `python3` on `PATH`
- From repo root: `export GOWORK=off` if a parent `go.work` lists unrelated modules

Build the CLI:

```bash
make build
# or: go build -ldflags "-X main.version=$(tr -d '[:space:]' < VERSION)" -o AgentGavel ./cmd/AgentGavel
./AgentGavel version
```

## FakeAdapter (harness proof)

Builds the in-repo Go fake adapter and runs the security suite in oracle mode.
Handshake reports **`provenance=unofficial`** (lab fixture — treat the run as
harness smoke, not a framework ranking).

```bash
go build -o /tmp/fakeadapter ./internal/engine/testdata/fakeadapter
./AgentGavel run \
  --adapter /tmp/fakeadapter \
  --suite security \
  --mode oracle \
  --scenarios SEC-001 \
  --seeds 3 \
  --out /tmp/ag-smoke-fake \
  --run-id smoke-fake-sec001
./AgentGavel report --json --root /tmp/ag-smoke-fake smoke-fake-sec001
```

Expect `results/smoke-fake-sec001/summary.json` and a SEC-001 row in the
scorecard.

## Sire adapter (unofficial)

Expected scorecard / Handshake **`provenance=unofficial`** (author-affiliated;
cannot self-ratify — ADR 007).

```bash
export PYTHONPATH=adapters/sire/src:sdk/python/src
./AgentGavel run \
  --adapter "python3 -m adapters.sire" \
  --suite security \
  --mode oracle \
  --scenarios SEC-002 \
  --seeds 3 \
  --out /tmp/ag-smoke-sire \
  --run-id smoke-sire-sec002
./AgentGavel report --json --root /tmp/ag-smoke-sire smoke-sire-sec002
```

Expect:

- `summary.json` / report JSON: `"provenance": "unofficial"`
- SEC-002 row present (numeric `score` or honest `"na": true`)

Adapter README: [`adapters/sire/README.md`](../../adapters/sire/README.md).

## LangGraph adapter (unofficial)

Expected scorecard / Handshake **`provenance=unofficial`** until a maintainer
signs off (ADR 007).

```bash
export PYTHONPATH=adapters/langgraph/src:sdk/python/src
./AgentGavel run \
  --adapter "python3 -m adapters.langgraph" \
  --suite security \
  --mode oracle \
  --scenarios SEC-001,SEC-007 \
  --seeds 3 \
  --out /tmp/ag-smoke-langgraph \
  --run-id smoke-langgraph-sec001-007
./AgentGavel report --json --root /tmp/ag-smoke-langgraph smoke-langgraph-sec001-007
```

Expect:

- `summary.json` / report JSON: `"provenance": "unofficial"`
- SEC-001 and SEC-007 rows present (numeric `score` or honest `"na": true`)

Adapter README: [`adapters/langgraph/README.md`](../../adapters/langgraph/README.md).
