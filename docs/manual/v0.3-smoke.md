# v0.3 local smoke

Copy-paste checks for reliability suite runs, `rubber-stamp`,
`report --publish` into a dashboard tree, and a local dashboard serve.
Run from the repository root unless noted.

Related manuals:

- [`rubber-stamp.md`](rubber-stamp.md) — SEC-002 + SEC-006 gate (ADR 011)
- [`leaderboard-pages.md`](leaderboard-pages.md) — Pages publish path (ADR 006)
- [`v0.2-smoke.md`](v0.2-smoke.md) — §8.1 adapters and `run --ci`

## Prerequisites

- Go toolchain (module `github.com/agentgavel/agentgavel`)
- `python3` on `PATH`
- From repo root: `export GOWORK=off` if a parent `go.work` lists unrelated modules

Build the CLI:

```bash
make build
# or: go build -ldflags "-X main.version=$(tr -d '[:space:]' < VERSION)" -o AgentGavel ./cmd/AgentGavel
./AgentGavel version
```

## Reliability suite (`run --suite reliability --ci`)

FakeAdapter + oracle mode should write REL-001..003 rows and exit `0`.
Stdout under `--ci` is the absolute path to `summary.json` only.

```bash
go build -o /tmp/fakeadapter ./internal/engine/testdata/fakeadapter
./AgentGavel run \
  --ci \
  --adapter /tmp/fakeadapter \
  --suite reliability \
  --mode oracle \
  --seeds 25 \
  --out /tmp/ag-smoke-rel \
  --run-id smoke-rel-v0
echo "exit=$?"
# stdout: /tmp/ag-smoke-rel/results/smoke-rel-v0/summary.json
```

Expect: `summary.json` contains scenario keys `REL-001`, `REL-002`,
`REL-003` with scores (FakeAdapter reports `hitl=true` / `ledger=true`,
so none are N/A). Exit code `0`.

Automated mirror:

```bash
go test ./cmd/AgentGavel -count=1 -run 'TestRunReliabilityFakeAdapterWritesRELRows'
```

## rubber-stamp (SEC-002 + SEC-006)

Harness proof with FakeAdapter. Full flag and exit-code table:
[`rubber-stamp.md`](rubber-stamp.md).

```bash
go build -o /tmp/fakeadapter ./internal/engine/testdata/fakeadapter
./AgentGavel rubber-stamp \
  --adapter /tmp/fakeadapter \
  --seeds 25 \
  --out /tmp/ag-smoke-rubber \
  --run-id smoke-rubber-stamp
echo "exit=$?"
# stdout: /tmp/ag-smoke-rubber/results/smoke-rubber-stamp/summary.json
```

Expect: `summary.json` scenario keys exactly `SEC-002` and `SEC-006`.
Exit `0` on FakeAdapter. No GSI or grade on stdout.

Automated mirror:

```bash
go test ./cmd/AgentGavel -count=1 -run RubberStamp
```

## `report --publish` (Unratified only)

Writes `dashboard/data/<run-id>.json` and updates `data/index.json`.
v0.3 rejects `--tab opt-in` (exit `2`, cites ADR 006).

Use any finished run under `results/` (or CLI testdata):

```bash
TMP_DASH=$(mktemp -d)
./AgentGavel report \
  --publish \
  --dashboard "$TMP_DASH" \
  --framework FakeAdapter \
  --adapter-name fakeadapter \
  --root ./cmd/AgentGavel/testdata \
  sample-catastrophic
echo "exit=$?"
# stdout: JSON string path to $TMP_DASH/data/sample-catastrophic.json
```

Expect: entry has `"tab":"unratified"`, `"sample":false`, and
`$TMP_DASH/data/index.json` lists `sample-catastrophic.json`.

Reject Opt-in:

```bash
./AgentGavel report \
  --publish \
  --tab opt-in \
  --dashboard "$TMP_DASH" \
  --root ./cmd/AgentGavel/testdata \
  sample-catastrophic
echo "exit=$?"
# expect exit=2
```

Automated mirrors:

```bash
go test ./cmd/AgentGavel -count=1 -run 'TestReportPublish'
go test ./internal/publish -count=1
```

## Local dashboard serve

Static site under `dashboard/` (marketing home + `/leaderboard/`):

```bash
python3 -m http.server -d dashboard 8000
# open http://127.0.0.1:8000/ and http://127.0.0.1:8000/leaderboard/
```

Expect: leaderboard HTML contains `id="opt-in"` and `id="unratified"`;
committed samples appear when JS loads `../data/index.json`.

Validate data without a browser:

```bash
bash scripts/check-dashboard.sh
# expect exit 0
```

Negative cases (expect exit `1`):

```bash
BAD=$(mktemp -d)
mkdir -p "$BAD/data" "$BAD/leaderboard"
cp dashboard/leaderboard/index.html "$BAD/leaderboard/"
cp dashboard/data/schema.json "$BAD/data/"
# Bad opt-in without sample
python3 - <<PY
import json, os
p = os.path.join("$BAD", "data", "bad-opt-in.json")
json.dump({
  "run_id": "bad-opt-in", "framework": "X", "adapter": "x",
  "adapter_version": "0", "provenance": "unofficial", "tab": "opt-in",
  "sample": False, "gsi": 0, "grade": "F", "pillars": {},
  "catastrophic": [], "na": [], "fingerprint": {},
  "generated_at": "2026-09-05T00:00:00Z",
}, open(p, "w"))
open(os.path.join("$BAD", "data", "index.json"), "w").write('["bad-opt-in.json"]')
PY
bash scripts/check-dashboard.sh "$BAD"; echo "exit=$?"

# Index omits an entry file
mkdir -p "$BAD/data2" "$BAD/leaderboard"
cp dashboard/leaderboard/index.html "$BAD/leaderboard/"
cp dashboard/data/sample-example-opt-in.json "$BAD/data2/"
echo '[]' > "$BAD/data2/index.json"
# remap: script expects data under <dash>/data — use nested dir
BAD2=$(mktemp -d)
mkdir -p "$BAD2/data" "$BAD2/leaderboard"
cp dashboard/leaderboard/index.html "$BAD2/leaderboard/"
cp dashboard/data/sample-example-opt-in.json "$BAD2/data/"
echo '[]' > "$BAD2/data/index.json"
bash scripts/check-dashboard.sh "$BAD2"; echo "exit=$?"
```
