# v0.2 local smoke

Copy-paste checks that the six RFC §8.1 unofficial adapters (Google ADK,
OpenAI Agents SDK, Pydantic AI, Microsoft Agent Framework, AWS Strands
Agents, CrewAI) produce a fingerprint + scorecard with
**`provenance=unofficial`**, and that `AgentGavel run --ci` exits with the
documented code map. Run from the repository root unless noted.

v0.1 smokes (FakeAdapter, Sire, LangGraph) remain in
[`v0.1-smoke.md`](v0.1-smoke.md).

## Prerequisites

- Go toolchain (module `github.com/agentgavel/agentgavel`)
- `python3` on `PATH`
- From repo root: `export GOWORK=off` if a parent `go.work` lists unrelated modules

Build the CLI:

```bash
make build
# or: go build -ldflags "-X main.version=$(tr -d '[:space:]' < VERSION)" -o AgentGavel ./cmd/AgentGavel
./AgentGavel version
```

## AgentGavel run --ci (exit codes)

`--ci` is non-interactive: stdout is the absolute path to `summary.json`
only (no `wrote ` prefix). Exit codes (UC-020):

| Outcome | Exit code |
| --- | --- |
| All pass | `0` |
| Any Fail | `1` |
| Catastrophic | `2` (wins over Fail if both) |

Usage / flag validation errors also exit `2` before scoring.

Harness proof (FakeAdapter + SEC-001):

```bash
go build -o /tmp/fakeadapter ./internal/engine/testdata/fakeadapter
./AgentGavel run \
  --ci \
  --adapter /tmp/fakeadapter \
  --suite security \
  --mode oracle \
  --scenarios SEC-001 \
  --seeds 3 \
  --out /tmp/ag-smoke-ci \
  --run-id smoke-ci-sec001
echo "exit=$?"
# stdout: /tmp/ag-smoke-ci/results/smoke-ci-sec001/summary.json
```

Automated mirror:

```bash
go test ./cmd/AgentGavel -count=1 -run 'TestCIModePrintsJSONSummaryPath|TestCIModeExitMapper'
```
