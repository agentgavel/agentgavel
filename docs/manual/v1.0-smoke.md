## Prerequisites

- Go toolchain (module `github.com/agentgavel/agentgavel`)
- `python3` on `PATH`
- From repo root: `export GOWORK=off` if a parent `go.work` lists unrelated modules

Build the CLI:

```bash
make build
# or: go build -ldflags "-X main.version=$(tr -d '[:space:]' < VERSION)" -o AgentGavel ./cmd/AgentGavel
./AgentGavel version
echo "exit=$?"
# expect exit=0
```

## `report --sign` (Opt-in signature)

Signs an Opt-in entry with the fixture maintainer key
(`example-framework-test-1`). Full workflow:
[`opt-in-submission.md`](opt-in-submission.md). Do **not** use this
fixture key for production Opt-in rows.

```bash
UNSIGNED=$(mktemp)
SIGNED=$(mktemp)
python3 - <<'PY' > "$UNSIGNED"
import json
print(json.dumps({
  "run_id": "smoke-sign-v1",
  "framework": "Example Framework",
  "adapter": "example",
  "adapter_version": "1.0.0",
  "provenance": "ratified",
  "tab": "opt-in",
  "sample": False,
  "gsi": 900.0,
  "grade": "AA",
  "pillars": {"chokepoint": 90},
  "catastrophic": [],
  "na": [],
  "fingerprint": {"hash": "abcd"},
  "generated_at": "2026-09-05T12:00:00Z",
}))
PY

./AgentGavel report --sign \
  --key internal/submit/testdata/example-framework-test-1.priv.b64 \
  --key-id example-framework-test-1 \
  --entry "$UNSIGNED" \
  --out "$SIGNED"
echo "exit=$?"
# expect exit=0; $SIGNED has key_id + signature

python3 -c 'import json,sys; m=json.load(open(sys.argv[1])); assert m["key_id"] and m["signature"]' "$SIGNED"
```

Unsigned `--tab opt-in` publish is rejected (exit `2`, cites ADR 013):

```bash
TMP_DASH=$(mktemp -d)
./AgentGavel report \
  --publish \
  --tab opt-in \
  --dashboard "$TMP_DASH" \
  --root ./cmd/AgentGavel/testdata \
  sample-catastrophic
echo "exit=$?"
# expect exit=2
```

Automated mirror:

```bash
go test ./cmd/AgentGavel -count=1 -run 'TestReportSignAndVerifyEntry|TestReportPublish'
```

## `verify-entry`

Verifies a signed entry against `dashboard/keys/registry.json`.

```bash
# reuse $SIGNED from the report --sign block above, or re-sign first
./AgentGavel verify-entry \
  --registry dashboard/keys/registry.json \
  "$SIGNED"
echo "exit=$?"
# expect exit=0
```

Tamper → exit `1`:

```bash
BAD=$(mktemp)
python3 - <<PY
import json
m = json.load(open("$SIGNED"))
m["gsi"] = 1.0
json.dump(m, open("$BAD", "w"))
PY
./AgentGavel verify-entry \
  --registry dashboard/keys/registry.json \
  "$BAD"
echo "exit=$?"
# expect exit=1
```

Usage / missing-file errors exit `2`.

CI mirror (every non-sample Opt-in file):

```bash
bash scripts/verify-opt-in.sh
echo "exit=$?"
# expect exit=0 on a clean tree
```

## `check-dashboard.sh`

Schema + ADR 006/007/013 rules on the committed `dashboard/` tree
(Opt-in = `sample=true` **or** verified signature).

```bash
bash scripts/check-dashboard.sh
echo "exit=$?"
# expect exit=0
```

Negative case (unsigned Opt-in with `sample=false`) → exit `1`:

```bash
BAD=$(mktemp -d)
mkdir -p "$BAD/data" "$BAD/leaderboard"
cp dashboard/leaderboard/index.html "$BAD/leaderboard/"
cp dashboard/data/schema.json "$BAD/data/"
python3 - <<PY
import json, os
p = os.path.join("$BAD", "data", "bad-opt-in.json")
json.dump({
  "run_id": "bad-opt-in", "framework": "X", "adapter": "x",
  "adapter_version": "0", "provenance": "unofficial", "tab": "opt-in",
  "sample": False, "gsi": 0, "grade": "F", "pillars": {},
  "catastrophic": [], "na": [], "fingerprint": {},
  "generated_at": "2026-09-05T00:00:00Z",
}, open(p, "w"))
open(os.path.join("$BAD", "data", "index.json"), "w").write('["bad-opt-in.json"]')
PY
bash scripts/check-dashboard.sh "$BAD"
echo "exit=$?"
# expect exit=1
```

## OpenClaw Handshake / SEC-002 (honest N/A)

Unofficial gateway-style sidecar (ADR 014). Reference Handshake keeps
`hitl=false` until a live Gateway probe; SEC-002 scores **N/A**, never
silent Fail. Details: [`adapters/openclaw/README.md`](../../adapters/openclaw/README.md).

Handshake unit smoke (pytest exit `0`):

```bash
cd adapters/openclaw
PYTHONPATH=src:../../sdk/python/src python3 -m pytest tests/test_scaffold.py -q
echo "exit=$?"
# expect exit=0; provenance=unofficial, hitl=false
cd ../..
```

`rubber-stamp` all-N/A fail-closed (exit `1`, stderr
`rubber-stamp: not_applicable`):

```bash
export PYTHONPATH=adapters/openclaw/src:sdk/python/src
./AgentGavel rubber-stamp \
  --adapter "python3 -m adapters.openclaw" \
  --seeds 3 \
  --out /tmp/ag-smoke-openclaw-rubber \
  --run-id smoke-openclaw-rubber
echo "exit=$?"
# expect exit=1
# stderr contains: rubber-stamp: not_applicable … hitl=false
```

Oracle SEC-002 companion (exit `0`, row `na:true`):

```bash

  --suite security \
  --mode oracle \
  --scenarios SEC-002 \
  --seeds 3 \
  --out /tmp/ag-smoke-openclaw-sec002 \
  --run-id smoke-openclaw-sec002
echo "exit=$?"
# expect exit=0; summary SEC-002 has na:true, provenance=unofficial
```

## Local Pages serve

Static site under `dashboard/` (marketing home + `/leaderboard/`):

```bash
python3 -m http.server -d dashboard 8000
# open http://127.0.0.1:8000/ and http://127.0.0.1:8000/leaderboard/
# Ctrl-C to stop; server process exit 0 on clean interrupt
```

Expect: leaderboard HTML contains `id="opt-in"` and `id="unratified"`;
JS loads `../data/index.json`. Validate data without a browser:

```bash
bash scripts/check-dashboard.sh
echo "exit=$?"
# expect exit=0
```

Pages deploy path after merge to `main`:
[`leaderboard-pages.md`](leaderboard-pages.md).
