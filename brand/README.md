## Geometry

- Two concentric rings (outer heavier, inner hairline).
- Vermillion stop-bar `#C23B22` with a center notch open to the right
  (gate / chokepoint).
- Ink `#1A1A1A` on light; near-white `#F5F5F5` rings/type on dark.
- Wordmark: “AgentGavel” as one word, system grotesque, medium weight.

## Usage

- Prefer the **icon** at 16–32px (favicon, avatar); lockup for README headers.
- Do not recolor the stop-bar except in the mono variant.
- Lockups use live `<text>` (system UI sans). For print or fixed packaging,
  outline the wordmark in a design tool before shipping.

## Do not

- Add a literal gavel, scales, AI sparkles, purple gradients, or glow.
- Add rim tick marks (removed in v2 for small-size clarity).
